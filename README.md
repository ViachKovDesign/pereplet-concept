# «Переплёт» — концепт-сайт книжного магазина

Вымышленный независимый книжный и маленькое издательство в Москве. Концепт-проект: бренд, книги, авторы, цитаты и адрес придуманы.
Дизайн и разработка — [ViachKovDesign](https://viachkovdesign.github.io).

Обычный HTML + CSS + JS, без сборщика. Анимации — GSAP + ScrollTrigger + Flip, плавный скролл — Lenis (лежат в `/vendor`). Без 3D и WebGL.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: герой «Книги, которые мы прочитали сами», выбор недели, лента новинок, «Что почитать, если…», афиша, подписка |
| `catalog.html` | Каталог: поиск, фильтры (жанр, цена, объём), сортировка, анимированная перестановка карточек |
| `book.html?id=sol` | Страница книги: обложка, аннотация, «почему советуем», «Отложить в магазине», «С этим берут» |
| `events.html` | Афиша: 6 мероприятий и запись (демо) |
| `about.html` | О магазине, три книги издательства, схема проезда, часы работы |

## Как открыть у себя (для новичка)

1. Скачайте проект: зелёная кнопка **Code → Download ZIP** на GitHub, распакуйте.
2. Можно просто дважды кликнуть `index.html` — сайт откроется в браузере.
   Но лучше запустить маленький локальный сервер (так работают переходы между страницами и загрузка данных). Откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 8080
```

3. Откройте в браузере `http://localhost:8080`.

Если Python нет — подойдёт расширение **Live Server** в VS Code (правый клик по `index.html` → *Open with Live Server*).

## Как опубликовать бесплатно (GitHub Pages)

1. Залейте файлы в репозиторий на GitHub (ветка `main`).
2. В репозитории: **Settings → Pages**.
3. В блоке *Build and deployment* выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
5. Сейчас сайт настроен на адрес `https://viachkovdesign.github.io/pereplet-concept/`. Если у вас другой — поправьте константу `SITE` в `tools/build.mjs` и запустите `node tools/build.mjs`: обновятся `canonical`, `og:url` и `og:image` на всех страницах.

## Как поменять книги

Все данные — в `data/books.json` (книги, мероприятия, настроения, часы работы). После правки:

```bash
node tools/build.mjs
```

Скрипт перепишет только куски HTML между метками `<!--gen:…-->` и обновит `js/data.js` (запасная копия данных, если сайт открыт как файл). Остальной HTML можно править руками — генератор его не трогает.

## Проверки

Нужен запущенный локальный сервер (см. выше) и Node.js с Playwright.

```bash
node tools/test.cjs screenshots/states
```

```bash
node tools/shoot.cjs screenshots/pages
```

- `tools/test.cjs` — автотест: поиск → фильтр → открыть книгу → отложить → счётчик в шапке +1, плюс настроения, формы, мобильное меню, reduced-motion и режим без JS;
- `tools/shoot.cjs` — скриншоты всех страниц на 375/768/1280/1920, проверка консоли и горизонтального скролла;
- `tools/icons.cjs` — пересобрать OG-картинку и фавиконы.
