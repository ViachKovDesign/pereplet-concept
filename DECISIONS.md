# Решения (по одной строке)

- Бренд: «Переплёт» — книжный в бывшей переплётной мастерской; всё вымышлено, включая адрес (Переплётный пер., 7) и улицы на схеме.
- Палитра: холодная газетная бумага `#EEEDE8`, краска `#131313`, акцент — ультрамарин `#2A2AD2` (цвет переплётного ледерина); не кремовый и не терракота.
- Шрифты: Unbounded (широкий гротеск с кириллицей, заголовки и цифры) + Literata (книжная антиква для текста); оба локально из `@fontsource-variable` 5.3.0, только кириллица+латиница, `font-display: swap`.
- Сетка: 12 колонок на десктопе, 6 на телефоне; «ломаность» — через разные `grid-column`, отрицательные/положительные `margin-top`, наложение слоёв и огромные контурные цифры позади.
- Защита от горизонтального скролла: `overflow-x: clip` на `body` и у секций с большими цифрами; бегущая строка обёрнута в контейнер с `overflow: clip`.
- Библиотеки: GSAP 3.12.5 (+ScrollTrigger, Flip) и Lenis 1.1.13 — из npm, лежат в `/vendor` без сборщика.
- Генератор `tools/build.mjs` — не сборщик: правит готовые HTML только между метками `<!--gen:…-->` (шапка, подвал, карточки, обложки), сайт работает и без его запуска.
- Обложки — SVG-символы, генерируются из параметров книги (10 стилей композиции), на каждую страницу кладутся только используемые.
- `book.html` содержит все 24 книги, нужная показывается через `:target` (работает без JS) или класс `.is-active` (с JS по `?id=`); ссылки имеют вид `book.html?id=…#…`.
- «Что почитать, если…» сделан на radio + `:has()` — переключается даже без JS; GSAP только добавляет анимацию.
- Переходы: View Transitions между документами (`@view-transition`), лист «перелистывается» клип-маской со скошенным краем; обложка «перелетает» через `view-transition-name: book-cover`.
- Фолбэк без View Transitions — шторка-лист на GSAP, плюс CSS-страховка: если скрипт не загрузился, шторка сама уходит через 2,5 с.
- Секции главной наезжают друг на друга через ScrollTrigger pin без `pinSpacing` (только ≥ 900px; на телефоне — лента новинок и обычный скролл).
- Лента новинок: при JS — горизонтальная прокрутка внутри закреплённого блока; без JS и в reduced-motion — обычный `overflow-x: auto` со snap.
- Магнитные ссылки и курсор «Открыть» — только при `hover: hover` и `pointer: fine`.
- Счётчик «отложено» — `localStorage` в try/catch, синхронизация вкладок через событие `storage`, бронь «живёт» 3 дня.
- Формы — демо: валидация на клиенте, ничего никуда не отправляется, об этом сказано рядом с формой.
- Мобильное меню — нативный `popover` (работает без JS), список отложенного — `<dialog>`.
- Даты афиши — 12 ноября — 27 декабря 2026 (ближайшие два месяца от даты сборки).
- Скриншоты в репозитории — JPEG (качество 62–78), чтобы не раздувать репозиторий.
- OG-картинка снята Playwright с героя главной, фавикон — SVG + PNG 32 и 180.
- Ширина 761–1100px: вторая обложка в герое скрыта, чтобы не наезжать на цифры.
